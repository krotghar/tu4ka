# raw/ — сырые источники

Инбокс для неизменяемых внешних материалов, которые предстоит заингестить в
вики: PDF/копии стандартов (например, AirNow Technical Assistance Document),
статьи, документация сторонних сервисов (sensor.community, madavi.de) и т.п.

Файлы здесь не редактируются после добавления — только читаются при ingest.
Положил новый источник — попроси заингестить, вики (`wiki/pages/`,
`wiki/index.md`, `wiki/log.md`) обновится по схеме из `CLAUDE.md`.
