# Roadmap и решения

## Запланировано

- **REST API для Android-клиента** — база уже есть, это `/api/v1/*`
  (`current`, `history`). Отдельного API-слоя под мобильный клиент заводить не
  планировалось — предполагается переиспользовать существующие эндпойнты.
- **Телеграм-бот** с уведомлениями о плохом качестве воздуха — переиспользует
  `server/aqi.py` (чистые функции, без зависимости от FastAPI), т.к. расчёт
  AQI уже вынесен из `main.py` именно с расчётом на такое переиспользование.
- **Мульти-тучковая версия** — несколько датчиков, аккаунты владельцев,
  публичная карта. Первый шаг (пакетирование `server/`) сделан, см.
  [server-package-layout](server-package-layout.md).
- **Сессия S1** — раннер миграций на `PRAGMA user_version` и новая схема
  (`devices`, `users`, `measurements` с `device_id`). Первый кандидат на
  репетицию через бету: пересев БД гоняет миграцию на боевых данных.

## Принятые архитектурные решения

- **Периоды `/history` — скользящие окна, не календарные.** Решение
  пересмотрено коммитом `fe61145` (редизайн дашборда) — было календарными
  (`day|week|month`), стало скользящими (`24h/7d/30d/12m/all`). См.
  [history-buckets](history-buckets.md) и [frontend-redesign](frontend-redesign.md)
  — там же почему привязку к сетке легко сломать незаметно (регрессия не
  ловится на `tz_offset=0`).
- **NowCast для `/current`, мгновенный AQI (+ lo/hi разброс) для `/history`.**
  См. [aqi-nowcast](aqi-nowcast.md) — разные методы намеренно, не оверсайт.
- **Свой SVG для графиков вместо Chart.js.** См. [frontend-redesign](frontend-redesign.md).
- **Один большой график с переключателем, а не график на метрику.** Показатель
  выбирается кликом по карточке, по умолчанию AQI; карточки и график читают
  общий `METRIC_DEFS`, чтобы не разъезжались. См.
  [dashboard-metric-selector](dashboard-metric-selector.md).
- **Макет дашборда живёт в проекте Claude Design**, а не в репозитории, и
  переносится в `index.html` руками. Значит, правки внешнего вида логичнее
  начинать с макета — иначе следующий импорт их затрёт. Отступления от макета,
  сделанные осознанно, перечислены на странице селектора.
- **`measurements.raw` хранит исходный JSON целиком** — страховка для будущих
  миграций схемы, при рефакторинге не выпиливать.
- **БД вне `/opt/tu4ka`** — чтобы `--delete` в rsync деплоя не мог её задеть.
- **nginx впереди, вторая среда `beta.amqi.am`, без Docker (сессия I1).**
  Бета — поддомен, а не префикс пути: `index.html` ходит по корневым путям, и на
  `/beta` страница молча читала бы API прода, а будущие `__Host-` куки сессий
  столкнулись бы на общем хосте. Даунтайм выкладки убран socket activation
  (сокет держит systemd, uvicorn берёт `--fd 3`), а не контейнерами — они его и
  не убирают. См. [nginx-tls-beta](nginx-tls-beta.md).
- **Версии зависимостей запинены целиком.** Со второй средой незапиненный
  `pip install` дал бы проду, бете и CI разные библиотеки, и бета перестала бы
  предсказывать прод. Апгрейд — отдельным коммитом через бету.
- **DNS в Cloudflare, но без проксирования.** Зона уехала в CF сама, вместе с
  режимом `DNS Records` у name.am; оранжевое облако намеренно выключено — оно
  ломает выпуск Let's Encrypt по HTTP-01 и не должно стоять на пути push, который
  не ретраится. См. [domain-dns](domain-dns.md), там же что теряем и чем это
  обратимо.
