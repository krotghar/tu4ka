1. What this license covers

Published measurements (PM2.5, PM10, temperature, humidity, pressure), derived aggregates (hourly summaries, the AQI index), and public (offset) sensor coordinates are distributed under the Creative Commons Attribution 4.0 International (CC BY 4.0) license. This page describes the license for the data only — the service's source code is not covered by it.

2. Attribution

3. Indicative nature of the measurements

All data consists of indicative measurements from consumer-grade airRohr sensors (SDS011 + BME280/BMP280), not from reference-grade air quality monitoring stations. Readings are subject to sensor drift, installation conditions, and the inherent inaccuracy of low-cost optical particulate sensors.

4. Why CC BY 4.0, not ODbL or DbCL

CC BY 4.0, unlike version 3.0, explicitly extends to the sui generis database right, which makes licensing the data itself unambiguous. ODbL (Open Database License) adds a share-alike requirement and notice obligations for derivative databases — a barrier for downstream data consumers that we want to avoid. DbCL (Database Contents License) is effectively a public-domain dedication for database contents, under which attribution becomes optional rather than expected.

A telling example: sensor.community's legal page states a "Database Contents License (ODbL 1.0)" but links to the text of DbCL 1.0 (opendatacommons.org) — the stated name and the linked license text disagree. We deliberately keep our license's name and its linked text consistent.
